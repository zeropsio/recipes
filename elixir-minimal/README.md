# Elixir Hello World Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->

A minimal Elixir app that boots a Plug + Bandit HTTP server and answers every request with a Hello World response, ready to deploy on Zerops with no database or other managed service to configure.
