# Angular Hello World — Remote Environment

This is a remote (CDE) environment for [Angular Hello World (info + deploy)](https://app.zerops.io/recipes/angular-hello-world?environment=remote-cde) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Remote (CDE)** environment allows developers to build the app **within Zerops** via SSH, supporting the full development lifecycle without local tool installation.
It includes a dev service with the code repository and necessary development tools, and a staging service for testing builds.
