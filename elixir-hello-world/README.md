# Elixir Hello World Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->
A complete [Elixir](https://elixir-lang.org) recipe for [Zerops](https://zerops.io) — featuring a Plug/Cowboy web application that connects to a PostgreSQL database via Ecto, demonstrates idempotent database migrations with `zsc execOnce`, and ships production-ready OTP releases alongside a live-development workspace. Includes ready-made configurations for every stage of the development lifecycle.
