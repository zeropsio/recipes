# Analog Hello World Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->
A complete [Analog](https://analogjs.org) Hello World recipe for [Zerops](https://zerops.io) — deploying the Angular meta-framework as a static SPA compiled by Vite and served by Nginx. Includes ready-made environment configurations for the full development lifecycle, from AI agents and remote development through stage and production.
