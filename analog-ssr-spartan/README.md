# Analog SSR Spartan Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->

This Analog SSR app combines Better Auth with [spartan/ui](https://spartan.ng/) — accessible Angular components on Postgres, with Valkey-cached profile reads, a NATS-driven activity feed indexed into Meilisearch, and presigned object-storage avatar uploads.
