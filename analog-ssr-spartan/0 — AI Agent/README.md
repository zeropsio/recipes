# Analog SSR Spartan — AI Agent Environment
This is an AI agent environment for [Analog SSR Spartan (info + deploy)](https://app.zerops.io/recipes/analog-ssr-spartan?environment=ai-agent) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->

**AI Agent** environment provides a dev + staging pair for AI agents to build and version the app, backed by low-resource Postgres and Valkey (**hobby** profiles, ~0.5 GB), plus NATS, object storage, and Meilisearch for iterating against the full stack.
