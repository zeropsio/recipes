# Medusa B2B — Local Environment

This is a local environment for [Medusa B2B (info + deploy)](https://app.zerops.io/recipes/medusa-b2b?environment=local) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Local** environment runs the production B2B backend and storefront in Zerops together with the managed data plane. Use zCLI VPN to point a laptop `yarn develop` at `db` / `redis` / `storage`, or keep the staged apps as the live preview.
