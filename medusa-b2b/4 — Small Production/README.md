# Medusa B2B — Small Production Environment

This is a small production environment for [Medusa B2B (info + deploy)](https://app.zerops.io/recipes/medusa-b2b?environment=small-production) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Small production** environment is entry production for a just-launched B2B shop — one Medusa container on the `prod` setup, `oltp-staging` PostgreSQL, staging Valkey, and Meilisearch. App RAM stays at 1 GB so admin does not OOM.
