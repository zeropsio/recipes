# Wasp Hello World - AI Agent Environment

This is an AI agent environment for [Wasp Hello World (info + deploy)](https://app.zerops.io/recipes/wasp-hello-world?environment=ai-agent) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**AI agent** environment provides a development space for AI agents to build and version the app.
It includes dev + stage pairs for the Wasp SPA (`appdev`, `appstage`) and API (`apidev`, `apistage`), plus a low-resource PostgreSQL database.
