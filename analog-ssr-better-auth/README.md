# Analog Ssr Better Auth Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->

This Analog SSR app uses Better Auth for email/password authentication on Postgres, with all the essentials for a real deployment — Valkey-cached profile reads, a NATS-driven activity feed that indexes into Meilisearch, and presigned object-storage avatar uploads.
