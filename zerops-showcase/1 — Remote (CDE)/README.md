# Showcase Recipe — Remote Environment

This is a remote (CDE) environment for [Showcase Recipe (info + deploy)](https://app.zerops.io/recipes/showcase-recipe?environment=remote-cde) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Remote (CDE)** environment allows developers to build the app **within Zerops** via SSH, supporting the full development lifecycle without local tool installation.
It includes dev and staging services for both the app and worker, along with low-resource PostgreSQL, Valkey cache, NATS message queue, and S3-compatible object storage.
