# Showcase Recipe — Local Environment

This is a local environment for [Showcase Recipe (info + deploy)](https://app.zerops.io/recipes/showcase-recipe?environment=local) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Local** environment supports local app development using zCLI VPN for database access, while ensuring valid deployment processes using a staged app in Zerops.
It includes a staging app and worker running in Zerops, with PostgreSQL, Valkey cache, NATS message queue, and S3-compatible object storage accessible via VPN.
