# NestJS Showcase — AI agent Environment
This is an AI agent environment for [NestJS Showcase (info + deploy)](https://app.zerops.io/recipes/nestjs-showcase?environment=ai-agent) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**AI agent** environment provides a development space for AI agents to build, test and version the app. Comes with `apidev`, `appdev`, `workerdev` dev runtimes paired with their `apistage`, `appstage`, `workerstage` deploy slots, and low-resource managed services for end-to-end iteration.
