# NestJS Showcase — AI Agent Environment
This is an AI agent environment for [NestJS Showcase (info + deploy)](https://app.zerops.io/recipes/nestjs-showcase?environment=ai-agent) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->

**AI Agent** environment provides a development space for AI agents to build and version the app. Comes with a dev runtime and a staging runtime for every codebase, plus low-resource managed services (Postgres, Valkey, NATS, Meilisearch, object storage) sized for iteration rather than load.
