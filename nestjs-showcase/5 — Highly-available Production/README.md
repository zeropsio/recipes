# NestJS Showcase — Highly-available Production Environment
This is a highly-available production environment for [NestJS Showcase (info + deploy)](https://app.zerops.io/recipes/nestjs-showcase?environment=highly-available-production) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Highly-available production** environment offers a fully redundant production setup. Dedicated CPU, SERIOUS corePackage on the project, HA mode on db/cache/broker, single-instance Meilisearch and object-storage with a 1 GB managed-RAM floor and 0.5 GB free-RAM headroom.
