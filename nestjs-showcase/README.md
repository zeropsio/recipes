# nestjs-showcase

<!-- #ZEROPS_EXTRACT_START:intro# -->
A NestJS REST API backed by Postgres, Valkey cache, NATS messaging, S3-compatible object storage, and Meilisearch full-text search, served to a Svelte SPA frontend with a standalone NestJS worker draining the NATS queue group. Six tier yamls take the same stack from agent-grade workspace through highly-available production — pick the tier that matches your operational shape and re-import a higher one when you outgrow it.
