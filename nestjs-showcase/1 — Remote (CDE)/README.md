# Nestjs Showcase — Remote (CDE) Environment

This is a remote (cde) environment for [Nestjs Showcase (info + deploy)](https://app.zerops.io/recipes/nestjs-showcase?environment=remote-cde) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Remote (CDE)** environment allows developers to build the app **within Zerops** via SSH, supporting the full development lifecycle without local tool installation.
It includes a app dev service with the code repository and necessary development tools, a app staging service, a api dev service with the code repository and necessary development tools, a api staging service, a low-resource database, a cache store, a messaging service, an object storage, and a search engine.
